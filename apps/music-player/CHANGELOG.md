# Changelog

本文件记录用户可见变化。较早版本可在 Git tag 和 GitHub Releases 中查看。

## v0.3.2 - 2026-09-10

- 迁移到 Apache License 2.0，并补齐 NOTICE、README 许可证信息与发布元数据。
- Release 资产新增 LICENSE 和 NOTICE，便于二进制分发时随附许可证与归属信息。

## v0.3.1 - 2026-09-10

- 修正公开文档中的版本号、运行状态和后续扩展说明。
- 增加发布记录，并让 GitHub Release 使用本文件作为发布说明。
- 忽略本地 `dist-*` 发版工作目录。

## v0.3.0 - 2026-09-10

- 每首内置曲目提供独立播放按钮，并隐藏面向用户的内部请求编号。
- 播放概览改为面向用户的自然语言。
- 增加插件界面中英文文案。
- 修正插件自报版本，并保持入口在停用状态下可见。
