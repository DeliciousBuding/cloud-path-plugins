# Changelog

本文件记录用户可见变化。较早版本可在 Git tag 和 GitHub Releases 中查看。

## v0.2.1 - 2026-09-10

- 修正最低 Core 版本声明和手动真板 E2E 的默认插件版本。
- 增加发布记录，并让 GitHub Release 使用本文件作为发布说明。
- 忽略本地 `dist-*` 发版工作目录。
- 将文档中的格式化示例改为只读检查。

## v0.2.0 - 2026-09-10

- 统一环境监测与安防告警为唯一应用。
- 温度、光照、接触和振动条件统一进入告警状态机。
- 支持通用 `tone` / `led` 动作，并在恢复或撤防时关闭 LED。
- 默认自动布防，同时保留手动布防、撤防和状态操作。
